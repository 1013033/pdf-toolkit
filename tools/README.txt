======================================================================
  Toolkit AGY - Microsoft Word 本機 100% 原生 PDF 轉檔小工具 (Windows)
======================================================================

【為什麼需要此工具？】
網頁瀏覽器因沙箱安全機制，無法直接讀取您本機作業系統的字型庫與微軟私有排版引擎。
此小工具讓您在「完全離線、免安裝、零外部網路傳輸」的前提下，直接調用您電腦中安裝的
Microsoft Word 核心（COM Automation）進行背景轉檔，產出 100% 原始向量品質的 PDF。

【系統需求】
- 作業系統：Windows 10 / 11 (或 Windows 7 / 8)
- 軟體需求：電腦需安裝 Microsoft Word (Office 2010 / 2013 / 2016 / 2019 / 2021 / Office 365)

【使用方法】
方法一（最推薦）：
  直接把一個或多個 Word 檔案 (.docx 或 .doc) 拖曳到「word-to-pdf-native.bat」圖示上放開，
  工具將自動在檔案同一個目錄下產出 100% 原生向量 PDF！

方法二（點擊選取）：
  滑鼠雙擊執行「word-to-pdf-native.bat」，會自動彈出原生檔案選取視窗，
  選取您要轉換的 Word 檔案（可按住 Ctrl 複選），點擊確定即自動轉檔。

【安全性與隱私】
- 100% 本機執行，無任何聯網傳輸，絕無資料外洩風險。
- 本工具為純開源批次檔與 PowerShell 腳本，隨時可用文字編輯器檢視原始碼。
